## Overview
Pingdom MCP(AI) Server는 관리자 시스템에서 LLM LOAD API 와 MCP 바탕의 Method를 활용한 비즈니스 로직을 제공하는 백엔드 애플리케이션입니다.

사용자 정보 기반 유동인구 분석 자료를 LLM 모델이 직원에게 전달하여, 유동인구 서비스를 제공합니다.
